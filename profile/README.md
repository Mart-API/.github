# Mart.dev

Lightning-fast public LinkedIn data in 1–2 seconds. Built for products, workflows, or AI agents.

- Enrich a person with available public profile data.
- Enrich a company with public company details.
- Refresh a contact and review possible role or employer changes.
- Prepare for a meeting with a profile and available public posts.

$0.24/1k records at scale. Start with 1,000 free credits.
